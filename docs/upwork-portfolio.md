# Upwork Portfolio Caption

## Project

Inbound operational voice-agent routing, verification, and QA system.

## Short Caption

I helped turn an inbound Leaping voice agent into a measured operational system: verification routing, backend lookups, protected-action gating, ticket/action proof checks, production call audits, and regression categories based on real failures.

## Technical Points To Mention

- Audited large call cohorts and mapped production failures into issue categories.
- Worked on phone, address/postal, and identifier fallback verification routes.
- Separated spoken claims from function-backed system truth.
- Flagged missing tickets, transfer misses, duplicate tickets, verification loops, false success claims, and unresolved drops.
- Helped shift delivery/status and protected actions from prompt reasoning toward backend evidence and deterministic exits.
